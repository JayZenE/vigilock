about vigilock

vigilock is a simple, secure, and cost effective file encryption application designed to help users protect their important files.

vigilock allows users to encrypt files using a password, turning them into protected .vigilock files. these files can then be decrypted using the same password when the user needs access to them again.

the application was designed with simplicity and security in mind, making file encryption easier to understand and use without requiring advanced technical knowledge.

how it works

  1. choose a file - select or drag and drop the file you want to protect.
  2. enter a password - enter a password to protect your file.
  3. encrypt - vigilock encrypts your file using AES-256-GCM and creates a .vigilock file.
  4. decrypt - upload your .vigilock file and enter the same password to recover the original file.

security

vigilock uses aes-256-gcm encryption to protect files. the encrypted file can only be successfully decrypted when the correct password is provided.
